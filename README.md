# Retail Analytics SQL Project

## 📌 Overview
This project is a SQL-based retail analytics system designed to analyze sales, customers, and product performance.

## 🛠 Tools Used
- MySQL
- SQL

## 📊 Problem Statement
Analyze retail data to generate insights on:
- Revenue performance
- Customer behavior
- Product performance
- Sales trends

## 🗂 Project Structure
- schema.sql → Database structure
- data_insert.sql → Sample dataset
- retail_analytics_kpi_analysis.sql → Business analysis queries

## 📈 Key Insights
- Electronics is the top revenue category
- Few products generate most revenue (Pareto principle)
- High-value customers contribute major revenue
- Revenue varies across months

## 🚀 Skills Demonstrated
- SQL Joins
- Aggregation
- Window Functions
- Business Analysis
